Model configurations and epoch budgets were chosen using internal validation, followed by a fixed-budget refit on all development images. These measurements use one grouped split and one seed. The SVM uses hand-written HOG and a linear squared-hinge objective optimized with Adam. Both optimizers use PyTorch. The chip reference is used after inference for position scoring.
