# Robot Vision Project
Computer vision project to recognise characters from an image

## Setting up environment
The codebase is tested on the conda environment defined in [`environment.yml`](./environment.yml). Build and activate the environment before running the task and demo code / notebook.

In the terminal:
```bash
conda env create -f environment.yml
conda activate robot_vision
```

## Tasks
- Task 1 to 4 have been attempted in the [`tasks.ipynb`](./tasks.ipynb) notebook.  
- Code and algorithm for the preprocessing functions are defined in [`preprocessing.py`](./preprocessing.py) and called in the notebook.
